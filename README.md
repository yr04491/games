# games

ブラウザで遊べる自作のクソゲー置き場です。

| No. | タイトル | 内容 |
|---|---|---|
| 001 | [ヒーターを守れ！](games/001-heater/) | 薪を集めてヒーターを燃やし続ける極寒サバイバル |
| 002 | [木、撃ちます。](games/002-tree-gunners/) | 人間の部隊がただの木を撃ち続ける放置ゲーム |
| 003 | [マグマが来るので3×3](games/003-magma-slide/) | スライドパズルを解いてマグマから逃げるパズルゲーム |
| 004 | [その音、全部ノーツ。](games/004-all-notes/) | マイクで拾った音をその場で譜面にする4レーン音ゲー |

## 構成

- `index.html` … ゲーム一覧ページ
- `games/<番号>-<名前>/` … ゲーム1本ごとのフォルダ（ゲーム同士でコードや素材は共有しない）
