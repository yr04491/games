## 構成

- `index.html` … ゲーム一覧ページ
- `games/<番号>-<名前>/` … ゲーム1本ごとのフォルダ（ゲーム同士でコードや素材は共有しない）
- `shared/medal.js` … 共通メダル（Firebase 匿名ログイン＋Firestore）
- `shared/firebase-config.js` … Firebase の設定値（空ならメダル機能はオフ）
- `firestore.rules` … Firestore のルール（自分のデータだけ読み書きできる）
